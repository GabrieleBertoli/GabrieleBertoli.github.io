# GabrieleBertoli.github.io

Gabriele Bertoli’s research portfolio, hosted on GitHub Pages at https://gabrielebertoli.dev.

Open `index.html` in a browser to preview the website locally. No build or installation is required.

- `index.html`: content and the inline catchment illustration.
- `styles.css`: colours, typography, and responsive layouts.
- `main.js`: mobile navigation, publication feed, and email copying.

The font loads from Google Fonts and recent publications load from ORCID. System fonts and publication profile links remain available offline.
